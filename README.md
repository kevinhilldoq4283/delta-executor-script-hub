## Delta Executor Overview

Delta Executor is a Windows desktop Roblox script executor intended for Lua injection, script imports, and repeatable execution tasks. Its compact local workspace includes a broad built-in script hub, allowing frequently used Roblox scripts to be accessed from one application.

Designed for PC users, the project provides batch execution, a queue that can persist between sessions, and automatic updating to help maintain the desktop installation over time. The lightweight interface also includes an integrated debugger and support for multiple UI languages.

Auto-update functionality is included, although compatibility may change when Roblox or the local application is updated.

### What distinguishes Delta Executor from similar tools?
Its main focus is a compact desktop interface combined with a 500+ script hub, batch execution, and a persistent queue for better organization.

### Could using it put my Roblox account at risk?
Third-party execution software may create account-related risks. Check the applicable terms and use the application responsibly.

### Are scripts saved on the computer?
The application uses a local Windows interface and supports queued scripts. Depending on how it is used, saved entries may remain on the device.
